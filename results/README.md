# Historical study outputs

These files predate the 7 October 2026 research audit and have not been regenerated or overwritten. Arithmetic agreement with an aggregate confusion matrix is not reproduction of an experiment.

Do not use clinical effect-size constants as measured participant results, synthetic control histories as evidence of real-user early detection, or direction agreement as external classifier performance. Original CSVs, participant measurements, preprocessing provenance and individual held-out predictions are needed to establish which historical findings can be retained.

See [the publication-readiness audit](../research/PUBLICATION_REVIEW.md), [machine-readable arithmetic checks](../research/audit_summary.json), and [the revised protocol](../research/EXPERIMENT_PROTOCOL.md). New private run outputs belong outside the checkout and must record their data and code provenance.
